# 🎯 Sintonia

Um jogo de festa inspirado no conceito de "Sintonia", desenvolvido
com HTML, CSS e JavaScript puro.

## 🎮 Como jogar

1. Defina os dois extremos do tema.
2. A roleta sorteia secretamente uma posição.
3. O jogador escolhe uma resposta pra aquela posição.
4. O outro jogador tenta posicionar o ponteiro onde acha que a resposta se encaixa.
5. Quanto mais próximos os ponteiros, mais pontos.

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript
